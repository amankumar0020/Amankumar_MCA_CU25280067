MCA203P-AS04 - Object Oriented Programming Using Java
Lab Sheet 04: Solutions to Questions 1-15

Files:
- Q1.java through Q15.java: one Java program per question
- Q12.java and Q13.java explain the requested concepts only, as specified in the lab sheet.

How to compile and run:
1. Install a Java JDK.
2. Open a terminal in this folder.
3. For example, compile Q1.java using: javac Q1.java
4. Run it using: java Q1
5. Repeat for each question number.

Each file has a public class matching its filename.
