MCA203P-AS03 - Java Lab Sheet 03
=================================

Contains Java source code for all 30 questions from the uploaded lab sheet.
Each program is in a separate file named Q1.java through Q30.java.

How to compile and run:
1. Install a JDK.
2. Open a terminal in this folder.
3. Compile a program: javac Q1.java
4. Run it: java Q1
5. Repeat with the question number you need.

Most programs use Scanner for keyboard input. Q19 and Q29 use predefined sample arrays.
Q23 finds the second-largest DISTINCT element.
Q30 follows the lab sheet definition: zero elements must be more numerous than non-zero elements.
