Java OOP Lab Sheet 05 — Solutions (20 programs)

How to use:
1. Extract this ZIP file.
2. Open each .java file separately.
3. Compile and run using:
   javac StudentMain.java
   java StudentMain

Important:
- Each program is a separate .java file.
- Keep the filename exactly the same as its public class name.
- Q7 is named PatientValidationMain.java to avoid confusion with Q4's PatientMain.java.
- These are beginner-friendly sample values; you may change them if your teacher asks.
