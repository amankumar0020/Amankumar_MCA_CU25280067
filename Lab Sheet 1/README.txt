Object Oriented Programming Using Java
Solutions for Questions 1-20

Files:
- Q1.java through Q20.java: individual Java programs.
- Each public class name matches its filename.

How to run:
1. Install a Java JDK.
2. Open a terminal in this folder.
3. Compile a program, for example:
   javac Q1.java
4. Run it:
   java Q1

Run each question separately. Programs that require input will ask for it in the terminal.
