MCA203P - Lab Sheet 02: Object Oriented Programming Using Java
Contains Q1.java through Q30.java, one file per question.

How to run:
1. Install a Java JDK.
2. Open this folder in VS Code or a terminal.
3. Compile and run one question at a time, e.g.:
   javac Q1.java
   java Q1

Use the matching question number in the filename and command.
