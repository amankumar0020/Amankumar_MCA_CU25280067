Java OOP Lab Sheet 06 - Solutions
=================================

This ZIP contains separate Java programs for Questions 1-11 from Lab Sheet 06.
Each question has its own folder. Open a terminal in a question folder and run:

    javac FileName.java
    java MainClassName

For example, in Q01_Animal_Cat:
    javac AnimalMain.java
    java AnimalMain

Question 11 reads 10 numbers from standard input. These are sample implementations
based on the tasks in the supplied lab sheet; change sample values/outputs if your
instructor specifies different details.
